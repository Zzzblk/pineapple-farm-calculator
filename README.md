# 菠萝农场计算器

逆水寒手游《菠萝农场计算器》的前端 HTML 预览版。当前阶段不依赖框架或后端，全部计算在浏览器本机完成，便于确认规则和交互后再迁移到微信小程序。

## 在线使用

<https://zzzblk.github.io/pineapple-farm-calculator/>

## 本地预览

在项目目录运行：

```bash
python3 -m http.server 4173
```

然后访问 <http://127.0.0.1:4173>。

## 已实现

- 15 分钟、60 分钟、6 小时桃子、16 小时四档作物
- 不施肥、蓝肥 +10%、紫肥 +30%、金肥 +50%
- 手动周末 +5% 加成
- 正算收获时间，以及按目标半熟或目标成熟时间反推种植时间
- 北京时间与设备本地时区
- 界面时间统一显示到分钟，内部仍保留整秒计算精度
- 分享/复制种植安排
- 浏览器本地保存上次选择，不上传数据

## 计算口径

- 总速度 = 1 + 周末加成 + 肥料加成
- 成熟时长 = 基础成熟时长 ÷ 总速度
- 四档作物半熟后距离成熟的基础时长分别为 3、5、10、10 分钟
- 内部结果按整秒向下取整，界面隐藏秒数
